# wine_quality_classifier
> A production-ready ML pipeline combining a text classifier with a pre-trained language model and RAG capabilities.

## Overview
This project builds an end-to-end AI application that ingest real-world data, trains a launguage model, and serves predictions through a chatbot interface with RAG support.

## Dataset
Dataset: UCI Machine Learning Repository – Wine Quality
Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). Wine Quality [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C56S3T.
The dataset contains physicochemical measurements of red and white wines, together with quality scores.
